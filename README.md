# 🎬 CineScope – Movie Discovery Platform

CineScope is a movie discovery web application that allows users to explore movies, search for their favourite films, watch trailers, and discover movies across different languages.

## 🚀 Features

- 🔍 Search movies by title.
- 🎥 Explore movie details.
- ⭐ Discover popular and trending movies.
- ▶️ Watch movie trailers.
- 🌍 Browse movies based on different languages.
- 📱 Responsive user interface.
- 🎞️ Get movie information using the TMDB API.

## 🛠️ Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript
- EJS

**Backend**
- Node.js
- Express.js

**API**
- TMDB API (The Movie Database)

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Abhilashpatel07/cinescope.git
```

2. Navigate to the project folder:

```bash
cd cinescope
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file in the root directory:

```env
TMDB_API_KEY=your_tmdb_api_key
```

5. Start the application:

```bash
node app.js
```

6. Open your browser:

```text
http://localhost:3000
```
